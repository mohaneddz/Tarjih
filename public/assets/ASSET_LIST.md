# Tarjih Result Assets

All PNGs have transparent backgrounds and are designed to work in both light and dark mode.

## Case / Weighing

- `tarjih-weighing-scale.png` — evidence weighing illustration
- `tarjih-ruling-rosette.png` — small emblem beside the ruling text

## Evidence authenticity

- `tarjih-evidence-authentic.png` — sound/authentic evidence
- `tarjih-evidence-good-hasan.png` — acceptable/good evidence
- `tarjih-evidence-weak.png` — weak evidence
- `tarjih-evidence-disputed.png` — disputed classification
- `tarjih-evidence-fabricated.png` — fabricated evidence
- `tarjih-evidence-unverified.png` — not yet verified
- `tarjih-authentic-stamp.png` — larger textured authentic stamp

## Ruling verdicts

- `tarjih-verdict-obligatory.png` — Obligatory / واجب
- `tarjih-verdict-recommended.png` — Recommended / مندوب
- `tarjih-verdict-permissible.png` — Permissible / مباح
- `tarjih-verdict-disliked.png` — Disliked / مكروه
- `tarjih-verdict-prohibited.png` — Prohibited / حرام
- `tarjih-verdict-non-obligatory.png` — Non-obligatory / غير واجب

The first five are the canonical five legal rulings. “Non-obligatory” is useful as a derivation result, but should not replace the canonical classification when a more precise ruling is known.
