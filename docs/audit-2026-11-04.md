# Dev-server audit — 2026-11-04

Ran `pnpm dev`, asked `/study` real questions, probed `/api/resolve` and `/api/query`, and walked every page.

## Bugs found

| # | Where | What | Status |
|---|-------|------|--------|
| 1 | `pipeline/prompts.ts` | Grounding prompt still says the only acts are `mistreat/1` and `consume/1` and tells the model to answer NONE otherwise. The KB has 13 domains now, so the model rejects fasting, loans, prayer, zakat — including the app's own suggested question "Can I skip the fast while travelling?". | Fixed |
| 2 | `pipeline/goal.ts` | Out-of-scope message says the KB covers "a handful of kinship acts and forbidden foods". | Fixed |
| 3 | `pipeline/llm.ts` | No retry on Groq 429. One question requests ~3.6k tokens against an 8k TPM free tier, so a second question inside a minute fails outright. | Fixed (waits and retries) |
| 4 | `/study` | A 429 shows the raw Groq error to the user, including the org id and an upgrade link. | Fixed |
| 5 | `/console?q=…` | Share links and "Open in console" fill the goal but never run it. | Fixed |
| 6 | `/console` | An atom the KB never mentions (`wine`, `horse`) silently returns no derivation instead of pointing to `khamr` / `horse_meat`. | Fixed |
| 7 | `/cases` | Ruling and Conflict columns render 20px stamp images that are unreadable on the dark theme; the columns look empty. | Fixed (text labels) |
| 8 | Home demo | "Permitted 55%" beats "Forbidden 100%" with no explanation that these are evidence strengths and specificity is checked first. | Fixed (labelled) |

## Not bugs

- Suggested-question chips on `/study` fill the input rather than submitting. Intentional.
- `/profile` and `/settings` already 404 — the project doc listing them as template pages is stale.

## Open

- Groq free tier still caps throughput at roughly one question a minute. Retrying hides short bursts, not sustained use.
- Narrow viewports were not checked.
